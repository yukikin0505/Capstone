    A · adjacency ãij, 0 = no link

    D · degree Σj ãij on the diagonal

    L = D − A · Laplacian every row sums to 0

    The graph is a balanced digraph: A holds both directions, aij = aji, so each drone's incoming weight (column sum) equals its outgoing weight (row sum). Blue = positive, red = negative; a stronger shade is a bigger number. A red struck-through entry is a link that is in range but dropped right now. Each drone's update is row i of L applied to the values it received, divided by γi|Ni|. The speed μ₂ and the delay bound τ_max are eigenvalues of that normalised matrix.
